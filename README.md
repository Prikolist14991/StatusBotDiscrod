# StatusBotDiscrod
Бот, написанный на Python с применением библиотек mcstatus, discord.py и ansi. Выполняет простую функцию - отображает количество игроков на сервере и ники этих игроков. 
Тестовая ветка. 

Кроме трех основных ботов, которые иногда будут изменяться, здесь будут и другие файлы, нужные для тестирования некоторых особенностей библиотеки discrord.py. Авось кому нужно будет.

```test_mind_bot.py``` - имеет новую команду "!writeip". Позволяет отслеживать данные, которые отслеживает ```try_mind_bot.py```, но позволяет менять адресс сервера без перезагрузки бота. 

Пример - !writeip 123.123.123.123 
Если "Адресс успешно получени", то
 пишем !echo
 Показывает кол-во игроков и никнеймы
Если "Данный айпи не сканируется", то либо сервер отключен, либо такого айпи нет
